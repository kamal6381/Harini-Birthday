## Publish and share on Harini's phone (GitHub Pages)
1. Extract this ZIP on your computer.
2. Open the extracted folder and check that `index.html`, `style.css`, `script.js`, `images/`, and `audio/birthday-music.mp3` are all together.
3. In a browser, sign in to GitHub and create a new repository. A simple name is `harini-birthday`.
4. Upload the website files and folders to the repository root (upload the contents of the extracted folder, not the ZIP itself). Make sure `index.html` is in the repository root.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**; choose branch **main** and folder **/(root)**, then Save.
7. Wait for GitHub Pages to publish the site. In Settings → Pages, copy the published `https://...github.io/.../` URL.
8. Open that URL on your own phone first. Test the login code `101106`, the photo gallery, and tap the music button to confirm the song plays.
9. Send the published URL to Harini on WhatsApp on November 10. She can open the link in her phone browser.
10. If you update any files later, upload the changed files to the same repository and wait for Pages to redeploy.

Important: the MP3 is included in the website files, so the hosting service will store and serve it with the site. The login code is a fun front-end gate, not strong security. Only upload photos and music you have permission to share.
